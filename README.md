# 長谷川式スケール採点シート

改訂長谷川式簡易知能評価スケール（HDS-R）を、パソコン・スマホで採点するための1ページのツールです。

- `index.html` だけで動く静的ページです（ビルド不要）。
- 入力内容はどこにも保存・送信されません。記録は「結果をコピー」でカルテ等に貼り付けます。
- 患者さんの氏名は入力しない運用です。
- 検索エンジンには載らない設定（noindex / robots.txt）にしています。

## 公開
GitHub の `main` に push すると、Vercel に接続していれば自動で本番に反映されます。

## 注意
HDS-R はスクリーニング検査で、点数だけで診断はできません。採点ルールは院内で医師の確認を受けてから使用してください。
